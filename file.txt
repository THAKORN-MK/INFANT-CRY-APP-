6) ตรวจว่า TensorFlow พบ GPU
-----------------------------
python -c "import tensorflow as tf; print('TensorFlow', tf.__version__); print(tf.config.list_physical_devices('GPU'))"

ผลต้องมี GPU:0 หรือ PhysicalDevice ที่ device_type เป็น GPU

ทดสอบให้มีการคำนวณบน GPU จริง:
python -c "import tensorflow as tf; a=tf.random.normal((2048,2048)); b=tf.linalg.matmul(a,a); print('Device:', b.device); print('Finite:', bool(tf.reduce_all(tf.math.is_finite(b))))"

11) หมายเหตุสำคัญ
------------------
- คำสั่ง Train ต้องรันเมื่อ prompt มี (audio-ml-gpu) เท่านั้น
- ก่อน Train ให้ตรวจ GPU:0 ทุกครั้ง
- TensorFlow อาจแจ้ง PTX JIT สำหรับ compute capability 12.0a ของ RTX 5070 Ti
  ข้อความนี้เป็น warning ไม่ใช่ error และการเริ่มใช้งานครั้งแรกอาจใช้เวลานานขึ้น
- ห้ามใช้ Python ฝั่ง Windows สำหรับ GPU training ของ TensorFlow 2.21
- Stage 2 checkpoint ระหว่าง Epoch จะอยู่ใน /tmp/cryinsight_checkpoints และคัดลอกกลับ Run folder หลัง Fold จบ ห้ามตั้ง CRYINSIGHT_CHECKPOINT_STAGING_DIR เป็น /mnt/c หรือ /mnt/d
- ให้รัน Full Training หลัง compatibility tests และ checkpoint smoke test ผ่านแล้ว

13) คำสั่ง Full Training (รันเมื่อพร้อมเท่านั้น)
------------------------------------------------
Stage 1:
python Models_dbl/binary/train_binary_dbl.py --train --device gpu --require-gpu --mixed-precision

Stage 2 single-branch:
python Models_dbl/Main/train_main_dbl.py --train --device gpu --require-gpu --mixed-precision --architecture corrected_single_branch

Stage 2 จะใช้ run_id เดียวกับ Binary run ล่าสุดอัตโนมัติ แต่ Binary run ต้องมี verification.json สถานะ complete ก่อน หาก Binary ล่าสุดยัง Train อยู่ Stage 2 จะหยุดและไม่เลือก Run เก่าแทน

Stage 2 multi-branch candidate:
python Models_dbl/Main/train_main_dbl.py --train --device gpu --require-gpu --mixed-precision --architecture corrected_multi_branch

ปิด feature cache เฉพาะเมื่อต้องการตรวจเทียบ:
เพิ่ม flag --no-feature-cache

กำหนด cache directory เอง:
เพิ่ม flag --feature-cache-dir /path/to/cache

17) ถ้าเปิด Ubuntu ไม่ได้: ตรวจสถานะก่อน ไม่ติดตั้งซ้ำ
-------------------------------------------------------
รันใน PowerShell (ไม่ใช่ Ubuntu):
wsl --version
wsl --list --verbose
Get-Service WslService,vmcompute -ErrorAction SilentlyContinue
Get-CimInstance Win32_ComputerSystem | Select-Object HypervisorPresent

สองคำสั่งต่อไปนี้เป็นการอ่านข้อมูล แต่ต้องเปิด PowerShell ด้วย Run as administrator:
Get-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform
bcdedit /enum

ถ้าขึ้น HCS_E_SERVICE_NOT_AVAILABLE ให้เก็บข้อความและผลตรวจข้างต้นก่อน
อย่า unregister Ubuntu, ลบ venv, เปลี่ยน boot policy หรือ reinstall เพื่อเดาสาเหตุ
ขั้นตอนนี้ไม่แก้ Windows features, BIOS หรือสั่ง restart เครื่อง
อ้างอิง: https://learn.microsoft.com/en-us/windows/wsl/troubleshooting
