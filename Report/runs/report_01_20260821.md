## 4. ข้อสังเกตเชิงผลลัพธ์

Stage 1 ให้ผลสูงทั้ง OOF และ locked internal Test แต่ยังมี source confounding ระหว่าง InfantCry-DBL กับ ESC-50 จึงไม่ควรตีความเป็นความสามารถทั่วไปนอก corpus

Stage 2 มี Final Test accuracy 92.41% และ Macro F1 91.02% ซึ่งยังไม่ถึงเป้าหมายการพัฒนา 97% จึงใช้ Run นี้เป็น baseline สำหรับ Shared Experiment Engine ผล Baseline/Ablation ต้องเลือกจาก grouped OOF เท่านั้น และจะรายงานเพิ่มเมื่อ Experiment Run complete

## 5. ข้อจำกัด

- Test เป็น locked internal held-out split จาก corpus เดียวกัน ไม่ใช่ external validation
- Split อยู่ระดับไฟล์ จึงป้องกัน exact-content family leakage แต่ยังไม่ยืนยัน subject-independent evaluation
- กลุ่ม Stage 2 เป็น operational labels จาก Dataset ไม่ใช่การวินิจฉัยทางการแพทย์
- Confidence score เป็น Softmax score ที่ยังไม่ได้ calibrated เป็น clinical probability
